# Meschange Copper Landing

صفحهٔ نمایش قیمت لحظه‌ای مس‌چنج با نمودار یک‌روزهٔ بایتکل.

## اجرای محلی روی مک

روی مک کافی است روی فایل `بازکردن-مس‌چنج.command` دوبار کلیک کنید. فایل، سرور محلی را اجرا می‌کند و سایت را در مرورگر باز می‌کند.

اجرای دستی:

```bash
python3 -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید.

## استقرار روی سرور (Production)

این پروژه کاملاً استاتیک است و هیچ مرحلهٔ build یا دستور اجرایی لازم ندارد. کافی است فایل `index.html`، تصاویر و پوشهٔ `fonts` را با همین ساختار روی هر وب‌سرور استاتیک، CDN یا سرویس میزبانی قرار دهید.

فایل `بازکردن-مس‌چنج.command` فقط میان‌بری برای اجرای محلی روی مک است؛ کد سایت در پروداکشن به آن وابسته نیست و آن را اجرا یا import نمی‌کند.

## داده‌ها

- قیمت خرید و فروش از API مس‌چنج دریافت می‌شود.
- نمودار یک‌روزه از ویجت بایتکل استفاده می‌کند.
- آخرین قیمت، سقف و کف از OHLC آخرین کندل روزانهٔ خود نمودار خوانده می‌شوند.
- آخرین OHLC و قیمت‌های API در مرورگر ذخیره می‌شوند تا هنگام قطع اتصال آخرین دادهٔ موجود نمایش داده شود.
- با کلیک روی لوگوی مس‌چنج، پنل مخفی همگام‌سازی قیمت خرید با آخرین قیمت نمودار باز می‌شود.
- همگام‌سازی قیمت خرید به‌صورت پیش‌فرض روشن است و کاربر می‌تواند آن را از همان پنل خاموش کند.
